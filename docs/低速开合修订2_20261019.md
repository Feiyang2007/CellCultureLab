我原先写"float64 原精度"，措辞不准。事实是：`get_dof_positions/velocities` 的读数和写进 `set_dof_actuation_forces` 的力矩缓冲区**都是 float32**，逐步记录只是**原样转记、不做额外四舍五入**，转成 Python float / JSON **不会增加底层精度**。
