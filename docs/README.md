## 7. 命名约定

- 报告：`主题_YYYYMMDD.md`，放在 `docs/` 根目录。
- 原始输出：`*_YYYYMMDD.txt` 或 `*.log`，放在 `docs/raw/`。
- 机器可读结果：`*.json`，由脚本生成；不要手工改。
- 结论必须写清适用范围：几何 / 关节级 / 短时 / 完整任务。
