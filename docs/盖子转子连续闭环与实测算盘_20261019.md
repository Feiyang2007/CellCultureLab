## 六、那个"−0.05 N·m 一动不动"的反常，怎么定性的

现象：真实重力下盖子停在 q=1.712，close 段给 −0.05 N·m（是参考在 q=0.7 处重力矩的 5 倍）连 180 步，位移精确为 0。

| 候选解释 | 实验 | 结果 |
| --- | --- | --- |
| PhysX 让刚体睡着了 | `probe_sleep_apis.py` 列出 `RigidBodyView.wake_up`，跑 `--wake each_step`（`wake_api="noarg"` 证明确实调到了） | **排除**：每步唤醒，读数一字不变 |
| 指令没送达 / 视图失效 | 零重力同资产同路径给 −0.05 → Δq 对应 a=−47.4 rad/s²，与 −0.05/I 精确一致 | **排除** |
| 限位把盖子"黏住"（关节摩擦） | 零重力下贴着上限位给 −0.02/−0.05/−0.075/−0.10，全部按 τ=I·a 自由响应 | **排除**：自由行程没有摩擦 |
| 该角度重力压入限位比力矩还大 | 曲线实测 τ_g(1.7)=+0.0743；`--fine` 扫描测得起跳阈值落在 0.05 与 0.10 之间；给 −2.0 N·m 立刻 −98.09° 关到底 | **成立** |

顺带两条工具性事实（都留了产物）：原生 access violation 出现在 Python 异常之后的收尾阶段，所以**退出码不能单独当物理层定位**；v1 报告里那次 shell 退出 139 仍按"异常退出，原因未定位"挂着，不升级为结论。

## 七、诚实记录的失败与返工

1. **判据定义错（已改，数字不改）**：第一次跑把 hold 段接在 open 段后面判"|Δq|<0.05° 即保持成功"，实测 +3.39652°。那是我的定义错——源关节 `damping=frictionloss=0`，带 0.236958 rad/s 余速进零输入段必然匀速滑行（0.236958×0.25 s = 3.397°，实测到小数第 3 位吻合）。修订=在中间补一个等值等时反向的 brake 段，原声明与原产物留在 `mini_lid_loop_none_cpu.first_run_as_declared.json`。
2. **参考键冲突（记账错，差点当成物理不符）**：参考里 `(rotor, +0.001, 零重力)` 出现两次（原生 trial5 与 armature=0.1 的 trial7），我按三元素建字典被后者覆盖，于是 `I_rotor` 算成 0.1、"与 3.3.0 不符"判成 false。修成四元素键后重跑 6 个配置，`spin_matches_330_within_tol` 才转 true。**这条提醒我：报告里任何"不符"先怀疑自己的算盘。**
3. **numpy 标量把整份 JSON 写挂**：`float32 is not JSON serializable` → 落盘失败后文件停留在上一次跑，差点把旧数据当新结论读。现在写盘统一走 `_json_default` 兜底，并把"读到的 status 与本次日志不符"当成硬错。
4. **`--label` 之前没生效**，两次真实重力跑写进同一个文件名，后者覆盖前者。现在文件名带配置签名（wake/力矩/label）。丢失的那次证据已由 `run_lid_real.log` 的段标记与重跑的 `mini_lid_loop_real_cpu_ct005_underpowered.json` 补回。
5. **勘误 2（已推翻）**：`重力补偿 + 固定偏置、无速度调节/无计划制动` 这一版策略超速：`lid_qstatic`（重力前馈 + 偏置）判据"峰值角速 < 2 rad/s" **false**，实测开 12.30 rad/s、关 17.79 rad/s（0.2 N·m 直推是 14.9/19.7 rad/s）。原因是这台设备盖子惯量只有 1.06e-3 kg·m²，起跳所需力矩本身就给出 >1e2 rad/s² 的角加速度。要慢速/软接触必须上**速度或阻抗反馈**（USD DriveAPI 速度目标或张量 `set_dof_velocity_targets`），而它的增益在这条链路上没有来源依据 → 记为"控制器类型缺口"，不拿临时调出来的增益冒充设备执行器行为。

# 第十一节 · 同日更正与低速闭环结果（回应《给千问的第三轮补充提示》）

四条意见我逐条复核后**全部成立**，下面每条都给出我自己独立验证的证据，不是照抄结论。

## 勘误 1：端点重力矩——限位处读数是"含约束净响应"，不是重力矩

我错在哪：2 步短采在 q=0 读到 v=0、Δq=0，就把曲线端点写成 0。但盖子贴着限位时**约束反力可以完全抵消重力矩**，`I·Δv/Δt` 在限位处量的不是孤立重力矩，缩短采样步数消不掉它。

我如何独立复核（不直接用 Codex 的数）：只用**自由行程点**（排除 q=0 那一行被钳位的读数）做最小二乘拟合定轴摆形式 `τ_g(q)=A·sin q + B·cos q + C`，再外推到端点。产物 `outputs/runtime_validation/mini_lid_gravity_torque_recheck.json`：

| 项 | 我的 Isaac 拟合 | 原 3.3.0 独立审计 | 差 |
| --- | ---: | ---: | ---: |
| q=0 | **−0.045683** N·m | −0.045650 N·m | 3.4e-5 |
| q=1.712 | **+0.074756** N·m | +0.074731 N·m | 2.5e-5 |
| 平衡角 | 0.584004 rad (33.461°) | 0.584521 rad (33.4906°) | 5.2e-4 rad |
| 拟合残差（17 个自由点） | 3.8e-6 N·m | — | — |
| 自由点 Isaac vs 原模型最大差 | 6.7e-5 N·m | — | — |

两条完全独立的路（Isaac 短采＋正弦外推 vs 原模型 −qfrc_bias＋质心力矩投影）在 4 位有效数字上吻合，所以采纳端点值。**修正后的界限：从闭合端起动开盖需 >0.04565 N·m；从全开端关盖需 >0.07473 N·m。** 我原先写的 0.0386 是 q≈0.1 的局部值，不能当端点界限。适用边界照抄参考里的声明：仅限"原模型、指定端点、静止、只考虑重力"的起动力矩分析，**不是**任意动态轨迹的力矩下界；有初速、惯性储能、接触或控制输入时要另算。内部平衡是**重力不稳定**平衡，两端保持靠行程限位，不能概括成"自由铰链有两个稳定内点"。

代码里这条不只是文字：`tau_g()` 之前直接线性插值这张表，于是低速控制器在 q=0 起步时前馈给成 0，第一次跑就以约 −77 rad/s² 砸向下限位（实测 `hold_at_start` 掉了 5.04°）。现在 `tau_g()` 用拟合式，系数与残差写进报告，缺 `mini_lid_gravity_torque_recheck.json` 直接失败。

## 勘误 2：负结果只否掉那一版策略，不否掉力矩控制

我错在哪：`lid_qstatic` 是 `τ = −τ_g(q) ± 常值偏置`，偏置 0.050/0.100 N·m 全程序不撤。I≈1.055e-3 时残余常值力矩就是 47.4/94.8 rad/s² 的**持续**加速度，没有速度调节、没有计划制动，越走越快是必然，跟"力矩接口能不能慢"无关。正确表述：**这一版"重力补偿＋固定偏置、无速度调节/无计划制动"的策略未达低速要求。**

## 勘误 3：`lid-lock` 是 joint 等式，不是 weld，且默认未启用

直接查源 XML（`.../model/instrument/centrifuge_tiangen_tgear_mini.xml` 第 72–74 行）：

```xml
<equality>
  <joint name="lid-lock" joint1="lid" polycoef="1.712" active="false" />
</equality>
```

eq_type=2 = 单关节多项式等式，目标是全开角 1.712 rad，`active="false"`，原 mini 的 instrument 类也没在 `_update` 里启用它。所以：本轮"保持段 0 位移"是**重力压向上限位＋限位反力**的结果，**没有验证任何锁定功能**，也不能说"全开时已经自动靠锁钉住"。可以说的只是"源声明了一条默认关闭的全开角锁定等式"——它仍是待迁移项。

## 勘误 4：通过范围再收紧

本轮通过的是**单件（mini）关节级运动与力—角响应试验**：固定底座、CPU 240 Hz、接触启用但**未发生也未验证真实任务接触**（内部碰撞按源规则过滤，地面留 1 mm 间隙、不与 mini 接触）。没有证明：机器人操作、夹具、取放管/插装等实际任务接触、锁盖功能、AutoBio 任何任务键、真实设备标定（参考里 `real_device_calibrated=false`）。另外按意见补上：`isaac_full_trajectory_validated=false`——我没有把整条轨迹逐点拿去对原模型，只对了端点、初加速度与几个协议末态。

## 低速连续开合——已做成（同一份资产、同一力矩接口、240 Hz、真实重力）

`--sequence lid_slow`，测试控制器 = 参考梯形轨迹 + 重力/惯性前馈 + 位置/速度反馈，输出仍是有限力矩：

| 设计量 | 值 | 来源 |
| --- | --- | --- |
| I_used | 1.05504e-3 kg·m² | 3.3.0 参考 `initial_acceleration` 反推 |
| 带宽 ω / 阻尼比 ζ | 30 rad/s / 0.7 | 声明值 |
| Kp = I·ω² | 0.94954 N·m/rad | 由上两项算出，可复算 |
| Kd = 2·I·ζ·ω | 0.044312 N·m·s/rad | 同上 |
| v_design / a_design | 1.0 rad/s / 20 rad/s² | 声明的期望速度（比 2 rad/s 硬顶低一档） |
| τ 饱和 | 0.25 N·m | 声明；全程未触发 |
| 起/终目标 | 0.10 与 1.60 rad | **两端各距限位 0.100 / 0.112 rad**，不靠撞限位停 |
| 容差 | 跟踪 ≤10 mrad；保持位置 ≤5 mrad、速度 ≤20 mrad/s；保持力矩与 −τ_g 差 ≤10 mN·m | 跑前定死 |

结果（`mini_lid_slow_real_cpu.json`，1140 步一次连续仿真、段间零复位）：**判据 23/23 全 true**。

| 段 | 实测 |
| --- | --- |
| hold_at_start | Δq +0.0026°，保持力矩 +0.038535 N·m（＝−τ_g(0.10)＝+0.038568，差 3.3e-5） |
