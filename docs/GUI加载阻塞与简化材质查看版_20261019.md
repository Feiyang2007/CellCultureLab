## 2026-10-19 朝向和材质更正（替代上一版 GUI 结论）

用户指出查看层朝向错误后，静态实测确认：原 v06 的 upAxis=Z、metersPerUnit=1；第一版查看层未显式写入，回落为 Y、0.01。该问题是 Codex 构建查看层遗漏元数据造成的。之前“原物理设置保留”的结论不完整：仅物理属性未改不代表单位与物理解释保持一致。第一版不得作为仿真或尺度验收依据。

已修正白模构建器，写入并重开核对 upAxis、metersPerUnit、timeCodesPerSecond、defaultPrim。同时新增 `outputs/gui_review/biolab_v06_color_zup.usda`：Z 朝上、米制，使用显式 Z-up 任务区相机。GUI 实际渲染约 83–86 FPS，设备选择和属性展示均响应；未按播放。新构建核对 7961 个本地 Gprim 的路径/类型及 physics/physx 属性与源一致，组合错误 0，原 v06 哈希未变。

不再统一覆盖为白色：286 个已有 UsdPreviewSurface 材质保留，225 个 MDL 材质按源颜色与贴图生成轻量近似，其中16个接入颜色贴图；3个无法直接提取颜色的材质保留明确登记的灰色回退。VRay 反射、折射、程序纹理并未等效烘焙，不能用于真实材质或视觉数据验收。四个远程机器人 payload 仍未加载；完整原 MDL 加载仍是未解决项。
