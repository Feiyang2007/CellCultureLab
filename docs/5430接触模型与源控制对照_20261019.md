# 5430 接触模型与源控制：第二轮诊断

W4 仍未验收。本轮找到了试点与完整源任务的控制/求解设置差异，并拒绝一组“正对插入成功、但偏位穿壁”的软接触候选。旧场景、原始几何和第一轮负结果保留；试验变更只写会话层与独立报告。

## 1. 原任务编译与控制核对

原始 `insert_centrifuge_5430.xml` 已在 MuJoCo 3.3.0 编译成功：2115 个 geom、42 个 body、30 个 qpos、28 个 DOF、1 个 keyframe。仅按源 `prepare()` 的原始 helper 递归设置机器人 gravcomp=1（23 个 body），没有执行专家、修改 XML 或迁移任务。

源专家是机器人关节位置控制，TOPPRA 规划关节轨迹（速度上限0.8、加速度上限0.6），每20Hz更新控制目标；从孔局部 +5mm 沿路径到 -30mm，保持抓取相对变换，随后夹爪指令240→190，等待200步。源肩/肘位置伺服 kp=2000、kv=100、力矩范围±150；腕部 kp=500、kv=25、±28。它们是关节参数，不能直接当作轴向夹具的笛卡尔刚度或推力。

源场景有效参数：dt=0.002s、implicitfast、impratio=10、elliptic cone、noslip_iterations=2、enableflags=16（multiccd）。此前重建夹具默认选项不同，且 dt=0.001s。第一轮一直标为几何诊断夹具，但不能将其结果升级为原完整任务失败。

新增 `--solver-profile source_task` 对照复用了源的 integrator/impratio/cone/noslip/enableflags，故意保留1ms步长隔离求解器选项影响；不是全部原配置复刻。正对管仍未插入，保持末轴坐标约 -2.494mm，撤回阶段仍卡在约 -2.541mm。由此不能将默认夹具配置当成全部问题的唯一原因。

证据：`5430_source_task_audit.json`、`5430_mujoco_servo_tasksolver.json`。原专家尚未执行；环境缺 jax/jaxlib/toppra，本轮未安装或替换规划器，没有伪造源专家轨迹。

## 2. 同一诊断位置伺服与摩擦对照

新增共享 `contact_fixture_protocol.py`：临界阻尼轴向伺服 Kp=200N/m、Kd≈2.06654N·s/m、推力上限1N，重力前馈；入口保持100步，平滑插入2000步，插入保持500步，撤回1000步。参考从+20mm到-30mm，再回+20mm。此参数是明示的测试执行器，非源机器人等价参数。

| 引擎/接触条件 | 插入保持末孔轴坐标 | 结果 |
|---|---:|---|
| Isaac 刚性接触、摩擦1 | -1.097mm | 未达目标，撤回成功 |
| MuJoCo默认夹具求解、摩擦1 | -16.478mm | 未达目标，撤回未完成 |
| Isaac 刚性接触、摩擦0 | -1.179mm | 未达目标，撤回成功 |
| MuJoCo默认夹具求解、摩擦0 | +0.079mm | 未达目标，撤回成功 |

零摩擦仅用于因果诊断，未并入任何基线。两引擎中关闭摩擦都没有解决插入，因此不能简单归因为摩擦过大；MuJoCo关闭摩擦后反而进入更浅，说明接触约束耦合也影响结果，不能只看单一系数推断。

## 3. 正式 PhysX 软接触候选：局部成功，但整体拒绝

安装版 PhysxMaterialAPI 正式支持 compliantContactStiffness/Damping/AccelerationSpring。源 solref=[0.02,1]、solimp=[0.9,0.95,0.001,0.5,2]。按源参考加速度公式在 d=d_width 处得到 k≈2631.579/s²、b≈105.263/s；在会话层用加速度式软接触测试并读回。

这只取了参考加速度系数，**没有迁移 MuJoCo 的阻抗插值/接触质量与多点耦合**，不能视作等价接触刚度。MuJoCo 官方解释与公式见 [3.3.0 Solver parameters](https://mujoco.readthedocs.io/en/3.3.0/modeling.html#solver-parameters)；其阻抗会同时影响有效响应与静态穿透，不能直接复制 k/b 充当完整映射。

- 正对：保持末 -28.995mm，距目标1.005mm，能撤回，未出现执行器饱和。
- 侧偏6mm：仍压入到 -19.551mm；虽然未达到位置目标，但已经明显进入孔壁。按原 MuJoCo 几何在记录位姿抽样复核，最大局部穿透 **6.017mm**；正对约 **1.143mm**。

因此拒绝该候选。`target_reached=true` 只是单项观测，不等于可采任务数据；不能将软接触调到“能塞进去”就记通过。本轮未改碰撞形状、未扩大孔、未缩管径。

证据：`5430_isaac_servo_compliant*.json`、`5430_compliant*_penetration.json`。穿透复核每20步采样，报告值不是连续时间精确峰值；同时仍保留 PhysX 原始逐步轨迹。

## 4. 几何适配搜索，避免无依据地继续换增益

在原始模型中，在5mm目标位置容差内搜索管平移，并另允许局部每轴±0.2rad倾斜；不改变任何几何。种子0，有限迭代的差分进化加Powell，运行前声明的候选判据为最大局部穿透≤50μm、位置误差<5mm。

- 仅平移：找到的最好候选仍约0.489mm穿透。
- 平移加倾斜：找到的最好候选仍约0.479mm穿透。

这不是全局不可行证明，也不是动态插入轨迹；源任务还有限定绝对高度的条件，本搜索只检验了位置距离，约束更宽。它提示：理想几何配合与源软接触假设应先核实，继续调硬夹具控制增益不一定能解决。

## 5. 状态与后续

已确认：几何完整、真实接触可读、标准软接触 API 可用、原始完整场景能编译、源控制/接触求解选项可追溯。未确认：源专家是否在此环境成功、接触动力学等价、单管插入任务、抓持顺应与机器人迁移。

下一步先做独立单接触的载荷—穿透/瞬态标定，将 MuJoCo 的阻抗与 PhysX 的接触模型差异量化，再以未参与标定的载荷验证；不直接在转子任务上调参凑通过。并准备原专家依赖与运行入口，保留20Hz关节位置控制、源求解设置和完整抓取接触。

本轮所有新增数据在 `outputs/runtime_validation/5430_contact_round2/`，`reviewed_summary.json` 为验收汇总，`monitor_reports.json` 为四次 Isaac 独立监测。四次原生试跑均正常完成、无捕获的 PhysX Error、无资源守卫中止、自建进程全部回收。主场景与千问 mini 文件未修改。
