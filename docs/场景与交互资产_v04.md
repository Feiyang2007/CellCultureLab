# CellCultureLab v04 — 场景与交互资产基础版

## 打开场景

双击工程根目录的 `启动场景_v04.bat`。v04 通过 USD 图层引用 v03；原始房间、工作台、机器人和现有仪器均保留，v03 文件未修改。

本版增加培养液槽，并完善现有移液区域的物理资产。启动时不自动执行任务、不自动播放物理仿真。

## 资产控制接口

`scripts/lab_assets.py` 提供 `LabAssets`，供后续控制器或数据生成程序调用。

- `set_control(name, value)`：给真实关节驱动设置目标。按压与退枪头单位为米，旋钮单位为度；越界值被拒绝。
- `attach_tip(tip_path)`：要求插接位置误差不超过 2mm、轴线误差不超过 10°，随后在实际位置建立固定约束；不移动或瞬移枪头。
- `eject_tip()`：要求调用方提供实际关节位置读取函数，退枪头机构实际到达释放行程后才解除约束。
- `aspirate(source, volume_uL)` / `dispense(destination, volume_uL)`：要求枪头已通过约束连接、末端进入容器目标区域，并检查容量、余额和液量守恒。
- `snapshot()`：输出驱动目标、实际测量（若调用方提供）、液量及容量；没有测量时返回 null，不把目标值当实际状态。
- 可选 JSONL 事件日志与仿真时间回调，便于后续接入数据记录。

液量目前是守恒的标量状态，接近条件是几何区域判定；尚不包含液体流动、飞溅、液面接触传感器或细胞生长模型。没有机器人策略、自动实验编排、图像数据导出或“完成任务”成功率声明。

## 验证

- `scripts/validate_v04.py`：场景结构、96 个枪头物理结构、关节连接及限位、容器摆放、v03 哈希不变。
- `scripts/validate_asset_interfaces.py`：插接拒绝条件、退枪头条件、液量守恒、容量约束与状态记录。
- `scripts/validate_asset_physics.py`：在独立小场景运行真实 PhysX，测量驱动后的位移/角度、单个枪头与支撑面接触、整架枪头的稳定性。

结果分别记录到本目录的 `validation_v04.json`、`interface_validation_v04.json`、`physics_validation_v04.json`。结构检查通过不等同于全场景动力学验收；物理结果以报告中的 passed 与逐项结果为准。

### 本次实测结果

三份验收报告均通过。PhysX 独立物理测试采用 1/240 秒步长、120 步（0.5 秒仿真时间）：

- 按压目标 −6mm，实际 −5.9999mm；退枪头目标 −7mm，实际 −6.9996mm。
- 旋钮目标 30°，0.5 秒时实际约 27.53°（此前 1.5 秒单资产测试约 29.98°）。
- 单个枪头自然倾倒后仍受到支撑面支撑，最低碰撞点约在地面上方 0.005mm。
- 整架 96 个枪头最大位移约 4.59mm，没有超过本次 15mm 的初步稳定性阈值。

以上是短时资产验收，不是长时间稳定性、机器人抓取成功率、枪头真实压配合力或完整实验流程验收。精确枪头碰撞块数量较多，首次碰撞缓存生成较慢；后续数据生成需要进一步做性能分级。
